MouseFix 隐私政策

生效日期：2026 年 11 月 13 日 · 版本 1.0

中文English

三句话：MouseFix 不收集你的数据，不联网，不需要账号。

它会读鼠标按键的类型、时间和光标位置，只为了判断一次点击是不是抖动；读完就丢，不记录、不上传、不截屏。

设置存在你自己的电脑上，卸载时删除。

一、这份政策管什么

MouseFix（以下简称「本应用」）是运行在 Windows 上的托盘工具，用来过滤鼠标微动老化产生的误双击、滚轮反向和拖拽断触。本政策适用于 Microsoft Store 版本和便携版，两者功能相同。

开发者：李东豫（Hank Li）。联系邮箱：matreshka999@icloud.com。

二、不收集什么

本应用没有账号系统，没有登录，没有遥测、统计、崩溃上报，也没有广告 SDK 或任何第三方组件。具体来说：

  • 不收集姓名、邮箱、电话、地址或任何身份信息。
  • 不生成设备标识、安装标识或用户标识。
  • 不记录你使用电脑的习惯、使用时长或应用清单。
  • 不采集剪贴板、文件、屏幕内容或键盘输入。
  • 不向任何服务器发送数据，包括开发者自己的服务器。

三、全局鼠标钩子读什么

过滤误点击必须在本应用里截获鼠标事件，这是本应用唯一的核心功能。它通过 Windows 公开的 SetWindowsHookEx(WH_MOUSE_LL) 接口读取以下字段：

  • 按键类型：左键、右键、中键、X1、X2、滚轮。
  • 事件类型：按下、松开、滚轮滚动方向。
  • 事件时间戳。
  • 光标在屏幕上的坐标。
  • 该事件是否由其他程序模拟注入（用于跳过模拟输入，避免干扰自动化工具）。

这些字段只在内存里参与一次判断：间隔是否短于阈值、滚轮是否在几十毫秒内反向、按住时间和移动距离是否构成拖拽。判断完立即丢弃，不写入磁盘，不形成历史记录，也不包含你点了界面上的哪个控件、点了什么内容、在哪个窗口里点。

本应用只监听鼠标，不安装键盘钩子，不读取键盘输入。

本应用不截屏，不读取窗口标题，不读取控件内容，不向其他进程注入代码。

四、拦下的事件和统计

托盘菜单顶部会显示「已经拦下多少事件」。这个数字只存在内存里，退出即清零，也可以手动点「Reset Statistics」清零。它不包含事件内容，也不上传。

拖拽保护会短暂压住一次松开事件（最多 150 毫秒），确认后面没有连续抖动后，再通过 Windows 的 SendInput 接口补发这次松开。补发的是你原本就按下并松开的那个按键，不包含额外信息。

五、设置存在哪里

设置只有三项：每个按键的阈值、每个按键是否启用、Smart Drag 是否开启。它们写在当前用户的注册表项：

HKEY_CURRENT_USER\Software\MouseFix

不包含任何个人信息。卸载方式不同，清理方式也不同：

  • Microsoft Store 版：按 MSIX 的注册表虚拟化规则，这些写入由 Windows 保存在应用自己的容器里，卸载应用时一并删除。
  • 便携版：直接写入上述注册表项。删除 exe 不会清掉它，需要手动删除 HKCU\Software\MouseFix，或在注册表编辑器里删掉这一项。

六、网络

本应用不发起任何网络请求。没有检查更新（商店版由 Microsoft Store 负责更新），没有云同步，没有在线配置，没有埋点。断网和联网时功能完全一样。

七、儿童

本应用不收集任何人的数据，也不区分年龄，因此不涉及儿童个人信息的收集或使用。

八、你的权利

由于本应用不收集、不存储、不传输个人信息，开发者手上没有可供查询、导出或删除的个人数据。如果你想清掉本机上的设置，按第五节的方法删除注册表项即可。

九、政策变更

如果以后的版本新增了联网、数据收集或账号功能，这份政策会在功能上线前更新，并在应用更新说明里注明。生效日期以本页顶部为准。

十、联系

对本政策有疑问，或发现了与本政策不符的行为，请发邮件到 matreshka999@icloud.com。

MouseFix Privacy Policy

Effective 13 November 2026 · Version 1.0

In three sentences: MouseFix collects nothing, connects to nothing, and requires no account.

It reads the mouse button type, event time and cursor position only to decide whether a click is a bounce. The data is used in memory and discarded. Nothing is logged, uploaded or screenshotted.

Settings stay on your PC and are removed when you uninstall.

1. Scope

MouseFix (the "app") is a Windows tray utility that filters false double-clicks, wheel reversals and dropped drags caused by worn mouse switches. This policy covers both the Microsoft Store version and the portable build; they work the same way.

Developer: Li Dongyu (Hank Li). Contact: matreshka999@icloud.com.

2. What the app does not collect

There is no account system, no sign-in, no telemetry, no analytics, no crash reporting, no advertising SDK and no third-party component. Specifically, the app does not collect:

  • Names, email addresses, phone numbers, postal addresses or any other identifier.
  • Device, installation or user IDs.
  • Your habits, usage time or the list of apps you run.
  • Clipboard contents, files, screen contents or keyboard input.
  • Anything sent to any server, including the developer's own.

3. What the global mouse hook reads

Filtering false clicks requires intercepting mouse events inside the app — that is its only core function. It uses the documented Windows API SetWindowsHookEx(WH_MOUSE_LL) and reads these fields:

  • Button: left, right, middle, X1, X2, wheel.
  • Event type: press, release, wheel direction.
  • Event timestamp.
  • Cursor position on screen.
  • Whether the event was injected by another program (used to skip synthetic input so automation tools are not disturbed).

These fields are used once, in memory, to decide whether the gap between presses is too short, whether the wheel reversed within a few dozen milliseconds, and whether hold time and pointer movement add up to a drag. Then they are discarded. Nothing is written to disk, no history is kept, and the app does not know which control you clicked or in which window.

The app listens to the mouse only. It installs no keyboard hook and reads no keystrokes.

It takes no screenshots, reads no window titles or control contents, and injects no code into other processes.

4. Blocked-event count

The tray menu shows how many events have been blocked. That number lives in memory, resets when the app exits, and can be cleared with "Reset Statistics". It contains no event data and is never uploaded.

Drag protection briefly holds back a release event (at most 150 ms), confirms that no burst of bounces follows, then re-issues that release through the Windows SendInput API. It re-issues the button you actually pressed and released, and carries no additional information.

5. Where settings are stored

There are three settings: the threshold for each button, whether each button is enabled, and whether Smart Drag is on. They are written to the current user's registry key:

HKEY_CURRENT_USER\Software\MouseFix

No personal data is stored there. Cleanup depends on how the app was installed:

  • Microsoft Store version: under MSIX registry virtualization, these writes are kept in the app's own container and removed by Windows when the app is uninstalled.
  • Portable version: writes go directly to the key above. Deleting the exe does not remove it; delete HKCU\Software\MouseFix manually, for example in Registry Editor.

6. Network

The app makes no network requests. There are no update checks (the Store version is updated by Microsoft Store), no cloud sync, no remote configuration and no analytics. It works the same online and offline.

7. Children

The app collects no one's data and does not distinguish by age, so it does not collect or use children's personal information.

8. Your rights

Because the app does not collect, store or transmit personal information, the developer holds no personal data to access, export or delete. To clear settings on your machine, delete the registry key described in section 5.

9. Changes to this policy

If a future version adds networking, data collection or accounts, this policy will be updated before that feature ships and the change will be noted in the app's release notes. The effective date at the top of this page is authoritative.

10. Contact

Questions about this policy, or reports of behaviour that contradicts it: matreshka999@icloud.com.
